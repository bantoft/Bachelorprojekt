Den overliggende hypotese for de endelige eksperimenter er følgene:
\begin{itemize}
    \item En diskret PINN kan approksimere næste tids state
    \item En diskret PINN kan iterativt approksimere tidsudviklingsoperatoren
    \item En diskret PINN kan approksimere kendte og ukendte fyisiske beygyndelsestilstande
    \item En diskret PINN kan approksimere kendte fysiske begyndelsestilstande på forskellige grid opløsninger
\end{itemize}
