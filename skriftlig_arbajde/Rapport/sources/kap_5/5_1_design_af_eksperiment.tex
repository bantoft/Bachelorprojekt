\subsubsection{Model arkitektur for endelige eksperiment}
Desværre overfittede de større modeller og da mindre modeller blev testet viste det sig at alle disse modeller overfittede. Derfor var 
det eneste man kunne tage med fra udforskningen i kapitel \ref{ch5_1_design_af_eksperiment} var, at tanh som aktiveringsfunktion var værre end SiLU, date loss konvergerede mod $2$,
PDE loss konvergerede mod $10^{-4}$, og PDE loss var meget ustabil.
Da konvergencen ad data loss og PDE loss kunne approksimeres skaleres data og PDE loss med deres approksimerede konvergensværdier. Derofer sættes loss til:
\begin{align}
    loss_{total} = 2 \cdot data_{loss} + 10^{-4} \cdot pde_{loss}
\end{align}

Da PDE loss skaleres med samme skala som data loss, medfører det at PDE loss er meget mere stabil og learning rate kan komme højere op.
Dette kommer af at når modellen skal afveje PDE loss mod data loss bliver den straffet hårdt med det samme. 
Dog blev det opsaveret at hvis modellen fik kæmpe loss i første batches, så kollapsede træningen og gav NaN værdier og kunne ikke redes.
Learning rate blev sat så højt som muligt uden at PDE loss blev ustabil, så modellerne kunne konvergere så hurtigt som muligt
Hyperparametrene blev sat til: batch størrelse på 1024, træning, validering og test split på $[0, 80\%]$, $(80\%, 90\%]$ og $(90\%, 100\%]$.
Hvor \texttt{Alexander\_e} splittes med tidsrække og \texttt{Alexander\_phi\_0} splittes med random sample, 100 epochs, og early stopping patience på 10 og min\_delta på 0.1.
