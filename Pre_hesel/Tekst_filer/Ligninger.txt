# HESEL: de 4 koblede PDE’er

Fra din PDF er HESEL skrevet som: 

[
d_t n + n \Kappa(\phi) - \Kappa(p_e)=\Lambda_n + \Sigma_n
]

[
\nabla \cdot d_t^0 \nabla_\perp \phi^* - \Kappa(p_e+p_i)=\Lambda_\omega + \Sigma_\omega
]

[
\frac{3}{2} d_t p_e + \frac{5}{2} p_e \Kappa(\phi)-\frac{5}{2}\Kappa\left(\frac{p_e^2}{n}\right)=\Lambda_{p_e} + \Sigma_{p_e}
]

[
\frac{3}{2} d_t p_i + \frac{5}{2} p_i \Kappa(\phi) + \frac{5}{2}\Kappa\left(\frac{p_i^2}{n}\right)-p_i\Kappa(p_e+p_i)=\Lambda_{p_i} + \Sigma_{p_i}
]

Hvor \Kappa operatoren er givet ved:

[
\Kappa(f) = -\frac{\rho_s}{R} \partial_y f
]

Og kilde termerne er givet ved:

[
\Sigma_n = S_e^n - \nabla \cdot (n \mathbf{u}_e^S)
]

[
\Sigma_\omega = (S_i^n-S_e^n) - \nabla \cdot \left(n(\mathbf{u}_i^S-\mathbf{u}_e^S)\right)
]

[
\Sigma_{p_e} = S_e^p - \frac{3}{2}\nabla \cdot (p_e \mathbf{u}_e^S) - p_e \nabla \cdot \mathbf{u}_e^S
]

[
\Sigma_{p_i} = S_i^p - \frac{3}{2}\nabla \cdot (p_i \mathbf{u}_i^S) - p_i \nabla \cdot \mathbf{u}_i^S
]
